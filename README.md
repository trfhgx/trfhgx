### Projects

- **[RepoTracer](https://github.com/repotracer/repotracer)**: coding agents burn most of their limits searching the codebase before they write anything. RepoTracer gives that search to a separate agent, so Claude Code and Codex get up to 2.7x more work from the same plan and write better code.
- **Webhound**: lets agents do anything on the web. Give it a goal and it gets it done, through any captcha or bot check, for as long as the goal takes.
- **TaskWin**: an AI that runs your day. It plans from your goals, keeps you on the plan, learns from how each day actually went, and has agents do the work they can do for you.
- **Skill Evolver**: agents forget what they learn when a session ends. Skill Evolver turns real work into lasting improvements, so your agents get better the more you use them.
- **Ops Center**: one place for everything happening across your apps and services. Every event lands there, and Ops Center decides who needs to know and reaches them wherever they are.
- **[Byto](https://github.com/trfhgx/byto)**: turns the Google Cloud and Vertex AI setup into one command and serves Gemini through the OpenAI API, so existing tools switch over without changes.
- **[Codex PR Debate Bot](https://github.com/trfhgx/codex-pr-debate-bot)**: makes coding agents defend their plan in the pull request before they touch code, so vague requirements and bad assumptions get caught before implementation.
